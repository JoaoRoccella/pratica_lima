# Prática de LIMA (Linguagens de Marcação)
Repositório modelo para a prática das linguagens de marcação HTML e CSS.

O objetivo desta prática é desenvolver as telas da interface gráfica do Windows 11 utilizando linguagens de marcação (HTML) e estilização (CSS), suas técnicas, conceitos e especificidades.

Você poderá utilizar as imagens contidas neste repositório `main` ou obter suas próprias imagens.

**Desenvolva as seguintes telas:**

1. **Booting**: tela de carregamento do sistema após pressionar o botão de ligar
2. **Welcome**: tela inicial que exibe a data e hora
3. **Logon**: tela de autenticação do usuário
4. **Desktop**: área de trabalho pronta, após o logon
5. **BSOD**: tela azul da morte (Blue Screen Of Death) ao tentar executar alguma ação no desktop, como clicar no menu iniciar

Adicione também efeitos de transição entre as telas, fontes e ícones, de forma a imitar com fidelidade o processo de logon do Windows 11.
