# Prática de LIMA (Linguagens de Marcação)
Repositório modelo para a prática das linguagens de marcação HTML e CSS.

O objetivo desta prática é desenvolver as telas da interface gráfica do Windows 11 utilizando linguagens de marcação (HTML) e estilização (CSS), suas técnicas, conceitos e especificidades.

Você poderá utilizar as imagens contidas neste repositório `main` ou obter suas próprias imagens.
