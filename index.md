# Windows 11 com HTML e CSS

Este projeto é uma recriação visual das telas iniciais do Windows 11, desenvolvida exclusivamente com HTML e CSS, sem uso de JavaScript ou frameworks. Ele simula, de forma estática e responsiva, as etapas clássicas da experiência de inicialização do sistema operacional: **booting**, **lock screen**, **tela de login**, **desktop** e até mesmo a icônica tela de erro **BSOD**. A proposta central foi explorar ao máximo as possibilidades visuais oferecidas pelas folhas de estilo em cascata, usando transições, gradientes, fontes customizadas e técnicas modernas de layout (Flexbox e Grid).

[Acesse aqui a página inicial do projeto](https://joaoroccella.github.io/pratica_lima/1_booting.html)

A motivação para este projeto surgiu do desejo de praticar a construção de interfaces realistas com foco em fidelidade visual e semântica na marcação HTML. Cada tela foi pensada como um exercício isolado de estilização, simulando elementos como janelas, barras de tarefas, planos de fundo dinâmicos e tipografia característica da interface da Microsoft, mas em ambiente web. O resultado é uma experiência navegável que pode ser utilizada como material didático ou inspiração para projetos que envolvam prototipação de interfaces.

Este repositório foi publicado com fins educacionais e faz parte de um portfólio voltado para o ensino e prática de **Linguagem de Marcação** no curso técnico de Desenvolvimento de Sistemas. Sinta-se à vontade para clonar, adaptar ou utilizar como base para exercícios em sala de aula ou desafios de front-end.
